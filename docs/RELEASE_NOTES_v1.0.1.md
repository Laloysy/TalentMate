## 已修复的缺陷

### P1 / 高优先级

| 编号 | 问题 | 修复 |
|---|---|---|
| BUG-003 | 提前提醒设为 **0 分钟**，保存后变回 **10 分钟** | 服务端 `reminder \|\| 10` 把 0 当成空值。改用 `normalizeReminder()`，只有未填时才回落默认值；更新接口同样处理 |
| BUG-005 | 关怀安排的**时间选择器无法上下滑动**，点开即卡死 | antd 时间滚轮在 Android WebView 中不响应触摸，改为原生 `<input type="time">`，交给系统选择器 |
| BUG-007 | **双击保存**创建出两条联系人 | 增加同步提交锁（`disabled` 挡不住同一 tick 的两次点击），服务端去重再兜一层 |
| BUG-009 | **姓名和邮箱完全相同**仍可重复创建 | 联系人创建/更新按邮箱（大小写不敏感）查重，重复返回 `409 DUPLICATE_CONTACT`；同名不同邮箱仍允许 |

### P2 / 中优先级

| 编号 | 问题 | 修复 |
|---|---|---|
| BUG-001 | 首页「新建日程」只跳到日程页，不打开新建表单 | 日程页此前从不读取 query，现支持 `?action=new`（并支持 `contactId` 预选） |
| BUG-002 | 日程卡片的**更多菜单被裁切**，邮件草稿入口点不到 | 卡片 `overflow-hidden` + 绝对定位导致裁切，改用 antd `Dropdown`（portal 到 body，自动避让屏幕边缘） |
| BUG-004 | 关闭提醒开关后退出再进入，**开关又自动打开** | 开关状态改为读取持久化偏好，系统权限只作为附加条件；通知同步在偏好关闭时不再重新排期 |
| BUG-008 | 删除联系人后日程**仍显示旧联系人姓名** | 删除成功后补刷新日程与今日摘要 |

### P3 / 低优先级

| 编号 | 问题 | 修复 |
|---|---|---|
| BUG-006 | 邮箱实际必填，但**没有必填标识** | 新增与编辑联系人表单补 `required` + 邮箱格式校验 |

### 其他

| 编号 | 问题 | 修复 |
|---|---|---|
| TC-075 | 编辑后直接离开，**没有「放弃未保存的修改？」确认** | 编辑器加入 dirty 跟踪，返回/关闭时弹出确认（放弃修改 / 继续编辑） |

**附带修复**：从月历 Bottom Sheet 点「邮件草稿」会因引用了不存在的
`setMailPreview` / `findContact` 而抛 `ReferenceError`，已修正为正常跳转。

**顺带调整**：设置页版本号改为从安装包读取（此前硬编码 `1.0 (Debug)`）；
Release 构建关闭 WebView 调试端口（`webContentsDebuggingEnabled: false`）。

## 验证

|---|---|---|

## 已知限制

与 v1.0.0 相同：

- **真机物理麦克风采集**未闭环（模拟器音频输入不可靠），其余语音链路已验证
- 厂商 ROM 的后台通知存活、刘海屏安全区、弱网、输入法遮挡需真机验证
- 后端仍为 HTTP 明文，生产环境应迁移到 HTTPS
