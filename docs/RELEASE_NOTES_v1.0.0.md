# TalentMate 伴贤 v1.0.0 · Android 首个可分发版本

语音驱动的职场关系关怀助手。对着手机说一句「明天下午三点安排和张伟的一对一沟通」，
自动完成语音识别、意图解析、建日程、绑定联系人并生成邮件草稿。

本版本是**首个可安装的签名 Release 包**（此前只有 debug 包）。

## 功能

**语音助手** — 说出「谁 + 什么时候 + 做什么」，自动建日程、绑定联系人、生成邮件草稿；
支持查询（「这周有什么安排」）、取消、改期，以及联系人重名时的消歧确认。

**关系管理** — 人才名册（员工 / 候选人分组、按姓名邮箱部门岗位搜索、CSV 粘贴导入）、
联系人详情与互动时间线、关系状态。

**关怀日程** — 月度日历、1对1 / 面试 / 生日 / 入职周年 / 录用 / 跟进等事件类型、
提醒设置、本地通知推送。

**邮件草稿** — 基于日程与联系人生成关怀邮件，支持编辑、预览、发送（SMTP）。

**关系洞察** — 关系热度图、高优先级 / 需关注 / 已安排统计。

**移动端适配** — 底部四 Tab 导航、语音悬浮按钮、安全区适配、
返回键分层处理（二级页 → 所属 Tab → 首页，浮层优先关闭）、
表单未保存时返回会二次确认。

**原生能力** — 麦克风与通知运行时权限（拒绝后状态与系统一致，不会假装成功）、
本地通知排期与点击跳转、网络状态监听、前后台生命周期同步。

## 本版本修复的关键缺陷

这些都是测试阶段真实暴露出来的问题，不是预设的待办项。

**1. 真机录音必然失败（`MODIFY_AUDIO_SETTINGS` 缺失）**
WebView 的 Chromium 采集音频要求 `RECORD_AUDIO` 与 `MODIFY_AUDIO_SETTINGS` 同时具备。
只声明前者时 `getUserMedia` 以 `NotAllowedError` 失败 —— 错误名具有误导性，
看起来像用户拒绝了权限，实际权限已授予。已补齐声明。

**2. 已删除账户的 token 仍被放行，导致写接口 500（幽灵账户）**
`authMiddleware` 原先只做 JWT 密码学校验，不检查用户是否还存在。
于是「账户已删除、token 未过期」的请求会带着不存在的 `user_id` 继续执行写操作，
最终撞上 `events.user_id` 外键约束，以 500「服务器内部错误」返回。
现在会校验用户存在性并返回 401，前端清 token 跳登录页。

**3. 联系人被删除后语音建日程 500**
语音意图里的 `resolvedContactId` 可能来自缓存，而联系人已被删除。
现在建日程前会校验联系人有效性，失效则退化为无关联日程。

**4. 超长日程标题导致 500**
`title` 超过 `VARCHAR(200)` 时 MySQL 抛 `Data too long` 被 catch 成 500。
现在把长度、时间格式、提醒范围等校验提前，返回明确的 400。

**5. 麦克风 `getUserMedia` 可能永久挂起**
部分设备上既不 resolve 也不 reject，界面永远停在「点了没反应」。
已加 10 秒超时，并把 `NotFoundError` / `TimeoutError` / `NotAllowedError`
映射为不同提示文案。

**6. 测试期间发现并修正的其他问题**
- 日程查询漏掉当天（服务端 `start_time <= endDate` 为闭区间，
  客户端改发 `YYYY-MM-DD 00:00:00` 并以次日 0 点为结束）
- 语音播报文案重复联系人（「和张伟和张伟」）
- 新手引导阶段弹出通知权限申请（违反「不主动打扰」原则），
  已拆分为静默检查与显式申请
- 日历最后一行被语音悬浮按钮遮挡
- 邮件编辑页有未保存内容时返回键绕过确认

## 已知限制

**请在真机上自行验证录音。** 模拟器的麦克风输入在 Windows 上不可靠：
安静环境与播放语音时测得的电平几乎相同，对照实验表明它拾取的音频内容不可控。
因此**真机物理麦克风采集这一段未能干净验证**，其余环节
（采集 → WAV 编码 → 上传 → 腾讯云 ASR → DeepSeek 意图解析 → 建日程 → UI 反馈）
均已验证通过。这是本版本唯一未闭环的环节。

其他未覆盖项：

- 厂商 ROM 的后台通知存活策略（需要真机省电策略表现）
- 刘海 / 水滴屏 / 手势导航的安全区（需要真机屏幕形态）
- 移动网络与弱网场景
- 真机输入法遮挡输入框

此外，后端以 HTTP 明文提供服务（`usesCleartextTraffic=true` + Capacitor
`allowMixedContent`），生产环境应当迁移到 HTTPS。
